# StyleHub — Premium Fashion & Apparel E-Commerce

**Internship Task ID:** WD-EC-002
**Domain:** E-Commerce — Fashion & Apparel
**Project Type:** Frontend-Only Web Application

StyleHub is a modern, responsive fashion e-commerce website created as part of the **Web Development Internship — Task WD-EC-002**.

The website provides a premium online shopping experience for **Men, Women, and Kids**, with product browsing, filtering, product details, wishlist, shopping cart, checkout, simulated authentication, user account management, and responsive design.

The project is built entirely on the frontend using **HTML5, CSS3, and JavaScript**. No backend or database is required. Product, cart, wishlist, user, and order data are managed using JavaScript and browser `localStorage`.

## 💾 Data Management

This is a **frontend-only project**, so no database or backend server is required.

The application uses JavaScript data structures and browser `localStorage` for managing application data.

The following types of data are handled locally:

```text
Products
Cart
Wishlist
Users
Current User
Orders
Addresses
Size Preferences
```

Example localStorage keys may include:

```text
stylehub_cart
stylehub_users
stylehub_current_user
stylehub_orders
stylehub_wishlist
stylehub_addresses
stylehub_preferences
```
